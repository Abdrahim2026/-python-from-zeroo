# 🐍 رحلة تعلم بايثون (Python Learning Journey)

مرحباً بك في مستودعي الشخصي لتوثيق وتتبع رحلتي في تعلم وصقل مهاراتي في برمجة بلغة بايثون! 🚀

هدف هذا المشروع هو بناء أساس قوي في لغة بايثون، وتطبيق المفاهيم النظرية عبر مشاريع عملية وتطبيقات برمجية متنوعة.

---

## 📂 هيكلية المشروع (Project Structure)

تم تنظيم المستودع بشكل مرتب ليسهل تتبع المواضيع:

*   📁 `01-Basics/` - الأساسيات (المتغيرات، أنواع البيانات، الجمل الشرطية، التكرار).
*   📁 `02-Data-Structures/` - هياكل البيانات (القوائم، القواميس، المجموعات، الصفوف).
*   📁 `03-Functions/` - الدوال والوحدات النمطية.
*   📁 `04-OOP/` - البرمجة كائنية التوجه (Object-Oriented Programming).
*   📁 `05-Projects/` - مشاريع تطبيقية صغيرة ومكتملة.

---

## 🛠️ الأدوات والتقنيات المستخدمة (Tech Stack)

*   **اللغة:** Python 3.x
*   **بيئة العمل:** VS Code / Jupyter Notebook
