📖 الدرس الأول: مقدمة عن Python

Python هي لغة برمجة سهلة التعلم وقوية، تُستخدم في الذكاء الاصطناعي وتطوير المواقع وتحليل البيانات.

أول برنامج لك:

print("Hello World!")

هذه التعليمة تعرض عبارة Hello World على الشاشة.

💡 نصيحة: لا تكتفِ بقراءة الأكواد، حاول كتابتها بنفسك.

📖 الدرس الثاني: المتغيرات وأنواع البيانات

المتغير هو مكان نخزن فيه المعلومات.

name = "Ahmed"
age = 15
price = 20.5
is_student = True

print(name)
print(age)

أنواع البيانات:

  • str : النصوص
  • int : الأعداد الصحيحة
  • float : الأعداد العشرية
  • bool : القيم المنطقية

📖 الدرس الثالث: الشروط If / Else

نستخدم الشروط لاتخاذ القرارات داخل البرنامج.

age = 18

if age >= 18:
    print("Adult")
else:
    print("Young")

إذا تحقق الشرط ينفذ البرنامج تعليمات if، وإلا ينفذ else.
